# 修订实验结果

完成主实验 62,400 次、补充实验 34,200 次、无结构对照 1,800 次及当前版本加密传输 3,000 次，共 101,400 次运行。

干净算法 67,200 次本地算法运行全部严格匹配 oracle；所有 31,200 次加噪运行保留，严格不匹配 1,213 次，其中真实距离 top-k 错误 588 次。全部严格失败通过穷举距离和记录配额独立重建。

默认干净 FedSeq 对 DANN 的 CPU 加速范围为 3.12–23.30 倍。共同隐私预算下，加噪默认比值为 1.02–1.33 倍；DNA IID 的配对区间包含 0，不声称稳定更快。

独立编辑生成器：DANN/FedSeq 比值 3.05–18.78；DANN+Bigram/FedSeq 比值 1.43–18.58。这些范围包括全部冻结种子和分区。

无结构对照各方法均计算 8,000 个精确距离；FedSeq 平均 181.60 ms，DANN 179.56 ms，说明存在无法获益的场景。

补充实验遇到输出冲突时按测量协议和完整性重跑，未按性能挑选；恢复记录见 supplement_recovery.json。完整原始 CSV、输入、指纹、完成凭据与独立重放结果均随包提供。

隐私参数与证明在两轮配额观察模型下对齐；该保证不等于全部主机轨迹、最终答案或跨查询累计预算的保证，浮点实验采样也不作为生产级精确采样认证。
